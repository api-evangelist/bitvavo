Bitvavo is a Netherlands-based European cryptocurrency exchange. It publishes a REST API, a WebSocket API, a Market Data Pro WebSocket API, an Institutional API and a FIX API for spot trading, market data, transfers and account management, authenticated with HMAC-SHA256 signed requests.

**Areas:** Company · Cryptocurrency · Exchange · Trading · Market Data · Netherlands
